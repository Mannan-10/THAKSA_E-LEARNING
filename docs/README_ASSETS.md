# SkillForge README Screenshots & Assets

To populate the screenshots section in the root `README.md`, capture and place the following images into this directory:

### Screenshots Checklist & Names:
1. **`home.png`** - Screenshot of the landing/marketing page.
2. **`courses.png`** - Screenshot of the public course catalog showing various bootcamps and workshops.
3. **`student-dashboard.png`** - Student dashboard view showing active course progress and registered batches.
4. **`instructor-dashboard.png`** - Instructor portal view showing course and live-session management.
5. **`admin-dashboard.png`** - Admin portal view showing course approval triggers and student role updates.
6. **`security-tests.png`** - Terminal screenshot showing the successful run of `npm test` inside the `Backend/` directory with all 7 security integration tests passing.

### Folder Directory Layout:
